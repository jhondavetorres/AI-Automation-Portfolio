# 🤖 AI Messenger Customer Support Bot

## 📌 Project Overview

This project is an AI-powered Facebook Messenger customer support automation built with n8n and Google Gemini. It automatically receives customer messages, generates intelligent responses, and logs conversations for business tracking.

---

## 🎯 Business Problem

Businesses often spend hours answering repetitive customer questions through Facebook Messenger. This results in delayed responses and increased workload.

---

## 💡 Solution

This automation instantly replies to customer inquiries using AI while recording every conversation into Google Sheets for future reference.

---

## 🛠 Technologies Used

- n8n
- Google Gemini AI
- Facebook Messenger API
- Webhooks
- Google Sheets
- HTTP Request

---

## 🔄 Workflow

```
Customer Message
       │
       ▼
Facebook Messenger
       │
       ▼
Webhook (n8n)
       │
       ▼
Google Gemini AI
       │
       ▼
Generate Response
       │
       ▼
Send Reply to Messenger
       │
       ▼
Save Conversation to Google Sheets
```
